# KinoPub-плагин: личный форк

Готовая связка с изменённой Lampa опубликована:
**[открыть приложение](https://dearlordylord.github.io/lampa/)** ·
**[гайд для Samsung](https://dearlordylord.github.io/lampa/guide.html)**.

Плагин уже встроен в сборку. Отдельно добавлять его не нужно.
В MSX: Settings → Start Parameter → Setup → `id:rgh:dearlordylord`.

Ниже — ограничения и результаты первоначальной проверки плагина.
Актуальные изменения ядра Lampa и проверки готовой связки описаны
[в PERSONAL-SECURITY.md](https://github.com/dearlordylord/lampa/blob/main/PERSONAL-SECURITY.md).

В этом форке отключены сервер автора, удалённые логи, синхронизация озвучки,
CUB-синхронизация выбора и сторонний CORS-прокси API. Сохранённые настройки
`kp_log_url` / `kp_proxy` не включат их обратно. API-запросы идут прямо на
`https://api.service-kp.com`, с Bearer-токеном в заголовке и OAuth-параметрами в теле.

Без авторского manifest-прокси используется штатный fallback: возможны ограничения
выбора аудиодорожек и 4K на Samsung. Просмотр и вход на реальном ТВ не проверены.

Не устанавливайте этот плагин в непроверенную Lampa с произвольными расширениями.
Плагины исполняются в общем контексте и могут читать токены друг друга.
Используй нашу сборку Lampa, ссылка выше: в ней отключены socket, remote configuration и CUB.

- Изменённый плагин: `docs/kp.js`.
- Проверки: `node smoke-test.js` (без сети, тестовые данные).
- Не запускайте `proxy-server/` и `log-server/`: их риски описаны в отчёте,
  серверы оставлены для сверки исходного кода и не используются форком.
- Старые APK, архив Kodi, сторонние образцы, логи и документ с чужими секретами
  удалены из текущего дерева. Они остаются в унаследованной истории Git;
  это не очистка истории и не отзыв опубликованных секретов.

Поддержка KinoPub отказала в выдаче новых ключей. Этот проект использует встроенный
общий идентификатор xbmc-клиента; 23 октября 2026 проверена выдача пятисимвольного кода без активации аккаунта.
Это не гарантирует, что общий клиент не будет отозван в будущем. Чужие приватные ключи из документов не используются.
